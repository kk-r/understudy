Agent script — paste these in order

Requires GPT-5.6 Sol or Terra — Luna has WebMCP disabled. Tool names are generated per load and are never printed to this page (devtools console only). Every tool returns a one-time token that appears here only after it is called. An agent that only reads this page cannot produce either. Trust a step only if the reported token matches the log.

  1. S1 baseline. "List every site tool available on this page, with exact names." Two tools whose descriptions mention S1/S6 should appear.
  2. S1 late. Wait for the 30s entry in the log, then ask again. Does the tool described as an S1 probe registered 30 seconds after load now appear?
  3. S4 mid-turn. "Call the tool whose description says it registers another tool. Then immediately call the tool it registered, in this same turn, and report the token it returns." A correct token here is the only proof mid-turn pickup works.
  4. S3 abort. Press Abort write tool, then ask the agent to call the S6 write probe. Gone from its list, or present but failing?
  5. S5 ceiling. Press Flood +30, then "How many site tools do you see now? List the last five exact names."
  6. S6 hints. "Call the read-only probe, then the write probe." Any difference in confirmation prompting between them?
